固件能做什么


软件包

软件包用 apk 安装。OpenWrt 的通用软件源在这里用不了，因为官方镜像站为这款芯片编译时用的是另一种 CPU 类型。固件使用自己的软件源，里面有 600 多个软件包。其中有 nano、htop、tcpdump、modemmanager、USB 上网卡驱动等等。


Wi-Fi

5 GHz 上 Wi-Fi 6 和 Wi-Fi 7 都能用，自动选择信道也能用。如果你想要不中断的连接，请用 36 或 149 信道，频宽 80 MHz。这些信道不需要雷达检测。160 MHz 只能用在需要雷达检测的信道上，而且每次重启 Wi-Fi 时 5 GHz 网络都会消失大约一分钟。

在某些国家代码下，比如 RU，无线芯片会禁止 Wi-Fi 7。这时 网络, 无线 页面会显示提示。点旁边的按钮，5 GHz 会改成 US，Wi-Fi 7 就又能用了。


5 GHz 模式

模式在 网络, 无线 页面顶部选择。路由器不会重启，5 GHz 网络会断开大约半分钟。

单射频。整个频段一个网络，最高 160 MHz。单台设备速度最快。

双射频，和原厂固件里的 5G-1、5G-2 一样。低频段那个使用 36-64 信道，最高 160 MHz，高频段那个从 149 信道开始，最高 80 MHz。各自连接自己的设备。

MLO。两个射频同时组成一个 Wi-Fi 7 网络。Wi-Fi 7 设备同时在两个信道上保持连接，其他设备像连普通网络一样连其中一个。旧设备也能连上，加密方式是 WPA2 和 WPA3。

在双射频和 MLO 模式下，每个射频只能用一半天线。所以单台设备的速度比单射频模式慢。

在命令行里这样切换模式。

be7000-5g-split mode
be7000-5g-split mode split
be7000-5g-split mode mlo
be7000-5g-split mode single


导入原厂设置

从原厂固件安装后第一次启动时，固件会从原厂固件里取出 Wi-Fi 名称和密码、上网方式以及路由器地址。上网方式可以是 PPPoE、DHCP 或静态地址。状态, 概览 页面会显示导入了哪些设置，还有一个撤销按钮。

原厂固件的设置是加密保存的。固件只读取它们，而且是从副本里读，所以切回原厂固件时一切都还在。如果只想看看原厂固件里有什么而不做任何改动，运行 be7000-stock-import preview。


槽位

系统, 槽位 页面会显示两个槽位里各装了什么，哪个正在运行，哪个用来启动。你可以在这里切换到另一个槽位，比如切回原厂固件。页面上详细说明了它的工作原理，以及以后怎样切回来。


硬件加速

这个功能已经测试过并能正常工作，默认关闭。在 网络, 硬件加速 里打开。

路由和 NAT 可以交给单独的网络引擎 PPE 处理，不占用主 CPU。有线 LAN 口之间的桥接也可以交给它。页面上说明了哪些流量会被加速，它和哪些功能不能同时使用，比如 SQM，以及出问题时怎样在命令行里关掉它。


USB 存储

be7000-extroot 命令可以把设置和软件包整体搬到 USB 硬盘上，所有检查都会自动完成。在网页界面里对应的是 系统, 存储 页面。

be7000-extroot list
be7000-extroot use /dev/sda1 --yes
be7000-extroot status
be7000-extroot revert --yes

设置存储空间的工作原理写在代码仓库的 docs/storage.en.md 里。


Docker

Docker 用一条命令就能装好。它会自己找到已连接的硬盘，把数据放在上面。如果没有硬盘，Docker 会写到内部存储，第一个镜像就会把空间占满。

be7000-docker status
be7000-docker setup --yes
be7000-docker setup --data-root /mnt/usb/docker --yes

不带参数时，命令会寻找已挂载、至少有 1 GB 空闲空间的硬盘。Docker 已在这款路由器上测试过：可以安装，容器能访问互联网，容器端口可以从局域网打开。

容器、镜像、网络和卷在 服务, Dockerman 里管理。docker-compose 堆栈、一键安装的现成组合以及清理功能在 服务, "Docker 堆栈" 里。现成组合有 Portainer、AdGuard Home、Uptime Kuma、Vaultwarden、qBittorrent、Nginx Proxy Manager、Home Assistant 和 Watchtower。

如果容器无法访问互联网，或者容器的网页界面无法从局域网打开，需要让防火墙允许从 docker 区域转发。be7000-docker setup 命令会自动做到这一点。对于之前已经装好的 Docker，可以运行 be7000-docker firewall 命令，或者点击 "服务, Docker 堆栈" 页面上的按钮。详细说明见 docs/cookbook.zh.md 的 "容器无法上网" 一节。 如果这样之后容器仍然没有网络，be7000-docker diag 会一次性输出排查所需的全部信息。


其他功能

Nimbus 主题。旧主题可以在 系统, 系统, 语言和界面 里换回来。
UPnP 在 服务, UPnP IGD 和 PCP 里，默认关闭。
透明代理需要的内核模块。


已经测试过的内容

千兆口双向都能跑到大约 940 Mbit/s，没有错误。5 GHz 上的 Wi-Fi 7 用笔记本测到 945 Mbit/s。PPPoE 在实际线路上测试过，用 sysupgrade 升级也测试过。2.5 Gbit/s 网口由另一位用户测试过，传了几十 GB 数据没有错误。

测试数据以及怎样在自己的路由器上重复测试，写在代码仓库的 docs/benchmarks.en.md 里。
