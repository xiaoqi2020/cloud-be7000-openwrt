# Beam WRT 能做什么

[Русский](features.md) · [English](features.en.md)

Beam WRT 是基于 OpenWrt 的小米 BE7000 路由器固件。这一页说明它有哪些功能，1.4 版本有什么新内容，以及它和原厂固件、其他固件有什么不同。

## Beam WRT 和其他固件的区别

**新的 OpenWrt，而不是厂商的旧代码。** 原厂固件用的是 Linux 5.4.164，编译于 2023 年 9 月。基于原厂的固件也停留在同一套高通代码上。Beam WRT 用的是 6.18.52 内核和最新的 Wi-Fi 驱动，安全修复和新功能也随之而来。

**一切都是开放的。** 源码、补丁和每个补丁的说明都在这个仓库里。任何人都可以编译出同样的固件，检查里面有什么。固件在 GitHub Actions 里编译，镜像和校验和发布在 releases 里。

**自己的软件源。** 有 600 多个软件包，可以直接在路由器上用 apk 安装。其中有调制解调器驱动、Docker、tcpdump、htop 等等。AmneziaWG 已经内置在固件里。hybrid-failover 放在单独的软件源里，新版本一出就会自动更新。在 "服务, 扩展程序" 页面一键就能安装，页面上也说明了它是什么、有什么用。

**一键更新。** "系统, 固件更新" 页面会找到新版本，检查校验和，然后保留设置安装。你自己装的软件包在更新后会自动装回来。有新版本时路由器会自己提示，顶部栏会出现按钮，状态，概览页面也会有提示区块。

**原厂固件随时可回。** Beam WRT 占用闪存里的一个槽位，原厂固件留在另一个槽位。点一个按钮就能回到原厂固件。如果新版本安装后启动不起来，路由器会自己回到原厂固件。

**启动日志写在闪存里。** 固件把启动日志写到一个单独的分区。即使在原厂固件里也能读到，所以不用拆机就能找到问题。

**有俄文、英文和中文文档。** 包括安装、更新、回退、常见任务的做法，以及可以自己重复的测速方法。

## 1.4 的新内容

主要内容在 1.4.0 中加入，1.4.1、1.4.2、1.4.3 和 1.4.4 又添加和修复了许多细节，完整列表在 [CHANGELOG.zh.md](../CHANGELOG.zh.md)。1.4.0 之后比较重要的有带 Zapret Manager 的扩展程序页面、新版本提示、修复后的 Docker 防火墙、指示灯的状态触发器，以及更可靠的 USB 磁盘更新。

### 新的基础

固件换到了新的 OpenWrt，内核是 6.18.52。Wi-Fi 驱动来自 backports 7.2，也就是最新的 ath12k 和 mac80211。1.3.1 里能用的功能在这里都能用。这次更新在一台实际使用的路由器上测试过，环境有 PPPoE、两个 Wi-Fi 频段和一个 USB 硬盘。

### 三种 5 GHz 模式

模式在 "网络, 无线" 页面顶部选择。路由器不会重启，5 GHz 网络会断开大约半分钟。

- **单射频。** 整个频段一个网络，最高 160 MHz。单台设备速度最快。
- **双射频。** 和原厂固件里的 5G-1、5G-2 一样。低频段用 36-64 信道，高频段从 149 开始，各自带自己的客户端。设备多的时候很方便。
- **MLO。** 一个 Wi-Fi 7 网络同时用两个射频，低频段是 160 MHz。Wi-Fi 7 设备可以同时在两个信道上保持连接，其他设备像连普通网络一样连接。老设备也能连上，加密方式是 WPA2 和 WPA3。

国家代码设为 RU 时，射频会不加任何提示地关掉 Wi-Fi 7，接入点按 Wi-Fi 6 工作。现在固件会提示这一点，旁边有个按钮可以只给 5 GHz 设成 US。

![单射频和 MLO 模式下的 5 GHz Wi-Fi 速度](img/bench-wifi-5g-zh.svg)

测试细节见 [benchmarks.zh.md](benchmarks.zh.md)。

### 从原厂固件导入设置

第一次安装时，固件会从原厂固件里取出 Wi-Fi 名称和密码、上网方式以及路由器地址。支持 PPPoE、DHCP 和静态地址。安装后路由器还在原来的地址，设备会自己连上 Wi-Fi，不用设置就能上网。

原厂固件的设置是加密保存的。Beam WRT 只读打开，而且是从副本读取，所以回到原厂固件时一切都还在。"状态, 概览" 会显示导入了什么，还有一个撤销按钮。

### 槽位和回到原厂固件

"系统, 槽位" 页面显示两个槽位里各装了什么，当前运行的是哪个，启动的是哪个。点一个按钮就能回到原厂固件，不用刷机，也不用编程器。页面上详细说明了引导程序怎么选择槽位，以及以后怎么回到 Beam WRT。

### 硬件 NAT 加速

IPQ9554 有一个单独的网络模块，叫 PPE。它自己就能做路由和 NAT，但 OpenWrt 到现在一直没用上它。1.4.0 版本加入了基于它的加速。这个功能基于 OpenWrt 的公开成果，但在 BE7000 上修好三个 bug 之前一直不能用。这些 bug 的说明见 [patches.zh.md](patches.zh.md)。

![开启加速后下载数据包的走向](img/ppe-packet-path-zh.svg)

这个功能已经测试过并能正常工作，默认关闭。在 "网络, 硬件加速" 里开启，页面上也说明了哪些流量会被加速，以及它和哪些功能不能一起用。

### 修复

- 切换 5 GHz 模式不会再让路由器重启。
- 设置了 MLO 网络后，"无线" 页面不会再报错。
- 移到 USB 硬盘上的设置在更新后会保留，UAS 硬盘盒里的 SSD 在启动时能被识别。
- "存储" 页面不会再提示格式化正在使用的硬盘。
- 主题里的下拉菜单又能打开了，宽表格也能放进屏幕。
- iPhone 的 USB 共享网络又能从软件源安装了。

完整的更新列表见 [CHANGELOG.zh.md](../CHANGELOG.zh.md)。

## 固件还有什么

- 在 "系统, 存储" 里一键把设置和软件包移到 USB 硬盘。
- Docker 和现成的容器组合（AdGuard Home、Home Assistant、Portainer 等），在 "服务, Docker 堆栈" 里。容器的防火墙会自动设置，包括 compose 堆栈使用的网络，并且可以和 Hybrid Failover 一起使用。
- 指示灯：LED 配置页面新增触发器 状态（Beam WRT），任何指示灯都可以显示进程、地址或命令的结果。琥珀色网络灯显示 2.4 GHz Wi-Fi 流量。
- Nimbus 主题。
- 俄文、英文和中文界面。
- UPnP，默认关闭。
- 用于透明代理的内核模块。

## 还没有测试的部分

有两件事需要在实际使用的路由器上测试，目前还没有条件做。

- **从原厂固件导入设置** 用测试数据测过，但还没有在真正的原厂固件上跑过。可以放心用 `be7000-stock-import preview` 看看固件能找到什么，它不会改动任何东西。
- **测量硬件加速在有线连接上的提升。** 加速功能本身已经测试过并能正常工作。对 Wi-Fi 来说提升不大，因为数据包还是要经过 CPU。有线连接上目前还没有测试数据。

如果你能帮忙，请把结果发到 4PDA 的帖子或 issues 里。测试方法见 [benchmarks.zh.md](benchmarks.zh.md)。
